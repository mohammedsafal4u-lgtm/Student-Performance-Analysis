#  Student Performance Data Analytics Project

##  Project Overview
This project performs an **end-to-end Exploratory Data Analysis (EDA)** on a student performance dataset using **Python**.  
The main goal is to analyze academic, demographic, and lifestyle factors that influence **students’ academic performance (CGPA)** and to extract meaningful insights using data visualization and statistical analysis.

---

##  Project Objectives
- Load and explore the dataset using Pandas
- Perform data cleaning and preprocessing
- Conduct **Univariate, Bivariate, and Multivariate Analysis**
- Apply **GroupBy operations, Pivot Tables, and Correlation Analysis**
- Create **10+ meaningful visualizations**
- Generate insights related to student academic performance

---

##  Dataset Description
- **Domain:** Education  
- **Number of Records:** 500+  
- **Number of Features:** 10+ (Numerical & Categorical)  
- **Target Variable:** CGPA (Cumulative Grade Point Average)  
- **Dataset Type:** Student academic and lifestyle data

##  Exploratory Data Analysis (EDA)
The following analyses were performed:

###  Univariate Analysis
- Age distribution
- Gender distribution
- Family income distribution
- CGPA distribution

###  Bivariate Analysis
- Study hours vs CGPA
- Social media usage vs CGPA
- Scholarship status vs CGPA
- Gender vs CGPA

###  Multivariate Analysis
- Study level vs CGPA by gender
- CGPA category distribution by gender
- Pair plot analysis

###  Correlation Analysis
- Correlation matrix
- Heatmap of numerical features

---

## Visualizations Included
- Bar charts  
- Line plots  
- Histograms  
- Box plots  
- Pie charts  
- Scatter plots  
- Heatmaps  
- Count plots  
- Stacked bar charts  
- Advanced plots (Pair plot, Violin plot)

---

##  Key Insights
- Increased **study hours positively impact CGPA**
- **Excessive social media usage** negatively affects academic performance
- **Scholarship holders** show higher average CGPA
- **Study level** has a stronger influence on CGPA than gender
- **Age has minimal impact** on academic performance
